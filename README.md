# ZCRUSH — VST3 Bitcrusher

**Версия проекта:** 1.1.0  
**Платформа:** Windows 10/11, x64  
**Формат:** VST3  
**DAW:** FL Studio и другие VST3-хосты  
**Фреймворк:** JUCE 7.0.12

ZCRUSH — эффект биткрашера с главным регулятором `CRUSH`, который одновременно усиливает квантование по битности и понижает частоту дискретизации. Визуальная концепция — индустриальный пресс, акустическая комната и персонаж внутри механизма. По мере увеличения `CRUSH` пресс опускается, индикаторы оживают, а сцена постепенно покрывается красными брызгами.

## Что находится в проекте

- `Source/PluginProcessor.*` — DSP, параметры, автоматизация и сохранение состояния.
- `Source/PluginEditor.*` — интерфейс, анимация пресса, персонаж и регуляторы.
- `Fonts/` — встроенные шрифты интерфейса.
- `.github/workflows/build.yml` — автоматическая сборка Windows VST3 через GitHub Actions.
- `CMakeLists.txt` — конфигурация JUCE/CMake.

## Быстрая сборка через GitHub Actions

Это самый простой способ получить готовый плагин без установки Visual Studio и CMake на свой компьютер.

1. Создай репозиторий на GitHub.
2. Загрузи **содержимое папки `ZCRUSH`**, а не саму папку целиком. В корне репозитория должны лежать `CMakeLists.txt`, `README.md`, `Source`, `Fonts` и `.github`.
3. Открой вкладку **Actions**. Workflow `Build ZCRUSH VST3 (Windows)` запустится после загрузки файлов. Также его можно запустить вручную через **Run workflow**.
4. Открой последний запуск workflow и дождись завершения шага `Build (Release)`.
5. Внизу страницы запуска открой раздел **Artifacts** и скачай `ZCRUSH-VST3-Windows-x64`.
6. Распакуй скачанный ZIP. Внутри должен находиться пакет `ZCRUSH.vst3`.

JUCE скачивается автоматически во время конфигурации CMake как архив фиксированной версии. Сборка выполняется Visual Studio 2022 x64.

## Установка в FL Studio

1. Закрой FL Studio.
2. Скопируй папку `ZCRUSH.vst3` целиком в:

   ```text
   C:\Program Files\Common Files\VST3\
   ```

   В итоге должен получиться путь:

   ```text
   C:\Program Files\Common Files\VST3\ZCRUSH.vst3
   ```

3. Запусти FL Studio.
4. Открой **Options → Manage plugins**.
5. Нажми **Find installed plugins** или **Start scan**.
6. Найди `ZCRUSH` в списке эффектов и добавь его на канал микшера.

Если Windows попросит права администратора при копировании — подтверди их. Не помещай `.vst3` внутрь папки `ZCRUSH.vst3` повторно: копировать нужно именно весь пакет один раз.

## Управление

| Контрол | Диапазон | Назначение |
|---|---:|---|
| **CRUSH** | 0–100% | Главная сила эффекта. Управляет глубиной биткрашинга и sample-rate reduction одновременно. При 0% сигнал проходит чисто. |
| **BIT DEPTH** | 1–16 bit | Целевая разрядность при увеличении `CRUSH`. |
| **SAMPLE RATE** | 1–32 | Коэффициент понижения частоты дискретизации при увеличении `CRUSH`. Например, `1/8` означает один удерживаемый сэмпл на восемь исходных. |
| **DRY / WET** | 0–100% | Баланс исходного и обработанного сигнала. |
| **OUTPUT** | −24…+12 dB | Выходной уровень после эффекта. |
| **BYPASS** | On/Off | Плавное переключение между обработанным и исходным сигналом. |

Двойной клик по любому регулятору возвращает его к значению по умолчанию. Значения параметров и состояние сохраняются в проекте DAW и доступны для автоматизации.

## Если GitHub Actions снова выдаст ошибку

В старом скриншоте был виден только общий текст `Process completed with exit code 1`. По нему невозможно отличить ошибку скачивания JUCE от ошибки конфигурации или компиляции. В этой версии workflow:

- выводит версии CMake и Git;
- явно указывает исходную папку через `cmake -S .`;
- загружает JUCE архивом, а не через `git clone` из FetchContent;
- отдельно проверяет, что пакет `ZCRUSH.vst3` действительно создан;
- завершает job с понятной ошибкой, если артефакт отсутствует.

Если сборка не пройдёт, открой упавший шаг **Configure** или **Build (Release)** и скопируй полный текст ошибки из его лога. Важны первые строки с `CMake Error`, `error C...` или `fatal error`; последняя строка `exit code 1` сама по себе причину не показывает.

## Локальная сборка на Windows (необязательно)

Для локальной сборки нужны Visual Studio 2022 с компонентом **Desktop development with C++** и CMake 3.22 или новее.

Из корневой папки проекта выполни в терминале:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel 2
```

Готовый пакет появится здесь:

```text
build\ZCRUSH_artefacts\Release\VST3\ZCRUSH.vst3
```
